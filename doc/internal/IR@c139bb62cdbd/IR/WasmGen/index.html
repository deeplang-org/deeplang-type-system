FieldByName → Field(index) resolution pass

Before code generation, we resolve all FieldByName occurrences in the ANF to concrete Field indices by scanning the type table. This is a global scan approach: field names are assumed to be unique across all struct types. TODO: carry type information in ANF for precise per-type field resolution.
